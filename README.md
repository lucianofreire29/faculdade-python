# Faculdade Python

Repositório destinado às atividades e aos projetos desenvolvidos durante as aulas da faculdade, utilizando **Python** para praticar lógica de programação, análise de dados e criação de dashboards.

## Objetivos

- Desenvolver o raciocínio lógico e a capacidade de resolver problemas;
- Praticar os fundamentos da linguagem Python;
- Organizar exercícios e projetos realizados durante as aulas;
- Trabalhar com tratamento e análise de dados;
- Criar dashboards para visualização de informações;
- Registrar a evolução dos estudos ao longo do curso.

## Conteúdos estudados

- Variáveis e tipos de dados;
- Operadores aritméticos, relacionais e lógicos;
- Estruturas condicionais;
- Estruturas de repetição;
- Listas, tuplas e dicionários;
- Funções;
- Manipulação de arquivos;
- Tratamento e análise de dados;
- Criação de gráficos e dashboards.

## Tecnologias e ferramentas

- Python
- Pandas
- Matplotlib
- Plotly
- Streamlit
- Git e GitHub
- Visual Studio Code

> As tecnologias serão adicionadas ao repositório conforme forem utilizadas nas aulas.

## Estrutura do repositório

```text
faculdade-python/
├── exercicios/
├── projetos/
├── dashboards/
└── README.md
```

- **exercicios:** atividades de lógica de programação e fundamentos de Python;
- **projetos:** trabalhos e projetos desenvolvidos durante o curso;
- **dashboards:** projetos de análise e visualização de dados.

## Como executar

1. Clone o repositório:

```bash
git clone https://github.com/lucianofreire29/faculdade-python.git
```

2. Acesse a pasta:

```bash
cd faculdade-python
```

3. Execute o arquivo desejado:

```bash
python nome_do_arquivo.py
```
